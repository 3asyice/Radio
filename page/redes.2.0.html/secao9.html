Protocolos e Serviços que Impulsionam a Web

Esta seção explora os protocolos e serviços que operam nas camadas mais altas do modelo OSI, diretamente interagindo com os usuários e as aplicações que utilizamos diariamente para navegar na web, transferir arquivos, enviar e-mails e realizar chamadas de voz.

Clique em qualquer termo para ver mais detalhes!

HTTP
Protocolo para transferência de hipertexto, base da World Wide Web.
HTTPS
Versão segura do HTTP, usando criptografia SSL/TLS.
FTP
Protocolo para transferência de arquivos entre computadores em uma rede.
SMTP
Protocolo padrão para envio de e-mails entre servidores.
Telnet
Protocolo de rede para acesso remoto a computadores via linha de comando.
SSH
Protocolo criptográfico para operações de rede seguras em redes não seguras.
PPP
Protocolo de camada de enlace de dados para comunicação direta entre dois nós.
PPPoE
Protocolo que encapsula frames PPP dentro de frames Ethernet.
VoIP
Tecnologia que permite a transmissão de voz em tempo real sobre redes IP.
ADSL
Tecnologia de linha de assinante digital que permite acesso à internet de alta velocidade sobre linhas telefônicas comuns.

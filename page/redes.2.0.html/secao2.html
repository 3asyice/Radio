Endereçamento e Protocolos de Rede

Esta seção aborda os conceitos fundamentais de endereçamento de rede e protocolos de comunicação. São elementos essenciais que permitem a identificação e comunicação entre dispositivos em redes.

Clique em qualquer termo para ver mais detalhes!

Address
Identificação única de um dispositivo ou localização em uma rede.
Endereço IP
Identificação numérica única de um dispositivo na rede usando protocolo IP.
Endereço MAC
Identificação física única e permanente de uma interface de rede.
Endereço de rede
Identifica a rede à qual um dispositivo pertence, parte do endereço IP.
Endereço de sub-rede
Identifica uma subdivisão lógica de uma rede maior.
Endereço de broadcast
Endereço especial usado para enviar dados a todos os dispositivos da rede.
Endereço de multicast
Endereço usado para enviar dados a um grupo específico de dispositivos.
Máscara de endereço
Define quais bits do endereço IP representam a rede e quais representam o host.
Máscara sub-rede
Máscara que define os limites de uma sub-rede dentro de uma rede maior.
IPv4
Versão 4 do protocolo IP, usa endereços de 32 bits (4 octetos).
IPv6
Versão 6 do protocolo IP, usa endereços de 128 bits para resolver limitações do IPv4.
TCP/IP
Suíte de protocolos base da Internet, combina TCP e IP para comunicação confiável.
UDP
User Datagram Protocol - Protocolo de transporte rápido sem garantia de entrega.
ARP
Address Resolution Protocol - Resolve endereços IP em endereços MAC.
Protocolo
Conjunto de regras que governam a comunicação entre dispositivos em rede.
Pacote (TCP)
Unidade de dados formatada para transmissão usando protocolo TCP.
Datagrama
Unidade de dados independente transmitida via UDP ou IP sem garantia de entrega.
Frame
Unidade de dados na camada de enlace, inclui cabeçalho e dados.
MTU
Maximum Transmission Unit - Tamanho máximo de dados que pode ser transmitido.
Unicast
Comunicação ponto-a-ponto entre dois dispositivos específicos.
Multicast
Comunicação de um para muitos dispositivos selecionados.
Broadcast
Comunicação de um para todos os dispositivos da rede local.

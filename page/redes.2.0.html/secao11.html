Como os Dados Encontram o Caminho na Internet

Esta seção explora os princípios e elementos fundamentais que permitem que os pacotes de dados viajem por vastas redes, atravessando fronteiras e alcançando seus destinos em qualquer lugar do mundo. Entenda como o roteamento conecta a todos.

Clique em qualquer termo para ver mais detalhes!

Roteamento
Processo de seleção de caminho para o tráfego em redes.
Routing
Termo em inglês para roteamento, o encaminhamento de pacotes.
Rota
Caminho que um pacote de dados segue de um ponto a outro na rede.
Tabela de Roteamento
Base de dados em roteadores com informações de como encaminhar pacotes.
Link
Conexão física ou lógica entre dois pontos em uma rede.
Backbone
Infraestrutura principal de alta capacidade de uma rede, conectando grandes áreas.
PoP
Point of Presence - Ponto de presença onde um ISP conecta-se a outros provedores.
Upstream
Direção do tráfego de dados que sai da rede local para a internet.
Downstream
Direção do tráfego de dados que chega da internet para a rede local.
Gateway
Dispositivo que conecta duas redes com diferentes protocolos.
Default Gateway
Dispositivo (geralmente um roteador) para onde o tráfego é enviado quando não há rota específica.

Termos Adicionais e Conceitos Complementares

Esta seção apresenta termos adicionais e conceitos complementares que enriquecem o entendimento sobre redes de computadores. São definições importantes para expandir seu conhecimento além dos fundamentos.

Clique em qualquer termo para ver mais detalhes!

Latência
Tempo que um pacote de dados leva para viajar de um ponto a outro na rede.
Throughput
Taxa real de dados transferidos com sucesso em um período de tempo.
Perda de Pacotes
Fenômeno onde pacotes de dados não chegam ao seu destino.
NAT (Network Address Translation)
Técnica que permite a múltiplos dispositivos compartilharem um único endereço IP público.
VPN (Virtual Private Network)
Cria uma conexão segura sobre uma rede pública, como a Internet.
QoS (Quality of Service)
Conjunto de técnicas para gerenciar o tráfego de rede e garantir desempenho.

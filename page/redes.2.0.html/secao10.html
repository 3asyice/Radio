Explorando a World Wide Web e a Rede Global

Esta seção aborda os conceitos fundamentais da World Wide Web e da Internet, desde sua estrutura e funcionamento até os serviços e ferramentas que utilizamos para interagir com o vasto universo digital.

Clique em qualquer termo para ver mais detalhes!

Web
A World Wide Web, sistema de documentos interconectados via internet.
WWW
Abreviação de World Wide Web, o sistema de documentos de hipertexto.
Browser
Software para acessar e exibir conteúdo da World Wide Web.
Navegação
O ato de explorar páginas e conteúdos na internet.
Site
Conjunto de páginas web e conteúdos relacionados hospedados em um domínio.
URL
Endereço único de um recurso na internet, como uma página web.
HTML
Linguagem de marcação para criar e estruturar conteúdo para a web.
Download
Transferência de dados de um servidor para um dispositivo local.
Upload
Transferência de dados de um dispositivo local para um servidor.
E-mail
Serviço de mensagens eletrônicas trocadas entre usuários.
Cloud Computing
Entrega de serviços de computação pela internet, como servidores, armazenamento e softwares.
Domínio
Nome que identifica um site na internet, como nomedosite.com.br.
WHOIS
Serviço de consulta a banco de dados de registro de domínios e IPs.

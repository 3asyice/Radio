Equipamentos Essenciais de Rede

Esta seção apresenta os principais dispositivos utilizados para construir e gerenciar redes de computadores. Cada equipamento tem funções específicas na infraestrutura de rede.

Clique em qualquer termo para ver mais detalhes!

Switch
Dispositivo que conecta dispositivos em uma rede local, criando uma rede comutada inteligente.
HUB
Dispositivo simples que conecta múltiplos dispositivos, repetindo sinais para todas as portas.
Roteador
Equipamento que conecta diferentes redes e direciona o tráfego entre elas.
Bridge
Dispositivo que conecta dois segmentos de rede, filtrando tráfego entre eles.
Repetidor de sinal
Equipamento que amplifica e regenera sinais para estender o alcance da rede.
Gateway
Dispositivo que conecta redes com protocolos diferentes, fazendo tradução entre elas.
Access Point
Equipamento que cria uma rede sem fio, permitindo conexão Wi-Fi para dispositivos móveis.
Ponto de Acesso
Termo em português para Access Point, dispositivo de acesso à rede sem fio.
NIC
Network Interface Card - Placa de rede que conecta um dispositivo à rede.
Transceiver
Dispositivo que transmite e recebe sinais, combinando transmissor e receptor.
Transceptor
Termo em português para transceiver, equipamento de transmissão e recepção.
Conversor mídia
Dispositivo que converte sinais entre diferentes tipos de mídia de rede.
Modem
Modulador-Demodulador que converte sinais digitais em analógicos e vice-versa.

Defendendo Ativos Digitais e Mantendo a Vigília

Esta seção explora os conceitos e ferramentas essenciais para proteger redes, dados e sistemas contra ameaças, além de discorrer sobre a importância do monitoramento contínuo para garantir a integridade e a disponibilidade.

Clique em qualquer termo para ver mais detalhes!

CFTV
Circuito Fechado de Televisão, sistema de monitoramento por vídeo.
Firewall
Sistema de segurança que monitora e controla o tráfego de rede.
VPN
Rede privada construída sobre uma rede pública para comunicação segura.
WEP
Padrão de segurança antigo e vulnerável para redes Wi-Fi.
WPA
Wi-Fi Protected Access - Sucessor do WEP com melhorias de segurança.
WPA2
Padrão de segurança mais robusto para redes Wi-Fi, com AES e CCMP.
SSH
Protocolo criptografado para operações de rede seguras.

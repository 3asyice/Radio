Meios Físicos de Transmissão de Dados

Esta seção apresenta os diferentes tipos de cabos, fibras e conectores utilizados para transmitir dados em redes de computadores. São os componentes físicos que permitem a comunicação entre dispositivos.

Clique em qualquer termo para ver mais detalhes!

Cabo UTP
Unshielded Twisted Pair - Cabo de par trançado sem blindagem, mais comum em redes.
Cabo Blindado
Cabo com proteção contra interferências eletromagnéticas.
Par Trançado
Dois fios entrela�ados para reduzir interferências e crosstalk.
Cat5
Categoria 5 - Padrão de cabo UTP para redes até 100 Mbps.
Cat6
Categoria 6 - Padrão de cabo UTP para redes até 1 Gbps.
RJ45
Conector padrão para cabos Ethernet, com 8 pinos.
Cabo Coaxial
Cabo com condutor central e blindagem, usado em TV e redes antigas.
Cabo Drop
Cabo de descida usado para conectar cliente final à rede.
Cabo Flat
Cabo achatado e flexível, usado em instalações internas.
Fibra Óptica
Meio de transmissão que usa luz para transportar dados em alta velocidade.
Fibra Monomodo
Fibra óptica para longas distâncias com um único modo de propagação.
Fibra Multimodo
Fibra óptica para curtas distâncias com múltiplos modos de propagação.
Fibra Reflexão
Princípio de funcionamento da fibra óptica baseado na reflexão total.
DIO - Fibra Óptica
Distribuidor Interno Óptico - Equipamento para organizar conexões de fibra.
Patch Panel
Painel de conexões para organizar e gerenciar cabos de rede.
Patch Cord
Cabo curto com conectores nas extremidades para interconexões.
Alicate Crimpar
Ferramenta para fixar conectores RJ45 em cabos UTP.

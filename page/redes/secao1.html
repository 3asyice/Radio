Conceitos Básicos de Redes de Computadores

Esta seção apresenta os termos fundamentais que formam a base do conhecimento em redes de computadores. São conceitos essenciais que todo profissional da área deve dominar.

Clique em qualquer termo para ver mais detalhes!

Binary
Sistema de numeração base 2, usando apenas 0 e 1, fundamental na computação.
Bit
Menor unidade de informação em computação, pode ser 0 ou 1.
Byte
Conjunto de 8 bits, unidade básica de armazenamento de dados.
bps
Bits por segundo, unidade de medida de velocidade de transmissão de dados.
Network
Conjunto de dispositivos interconectados para compartilhar recursos e informações.
Net
Abreviação de Network, refere-se a uma rede de computadores.
Rede Local
Rede de computadores em uma área geográfica limitada, como escritório ou casa.
LAN
Local Area Network - Rede de área local, conecta dispositivos próximos geograficamente.
MAN
Metropolitan Area Network - Rede metropolitana, cobre uma cidade ou região metropolitana.
WAN
Wide Area Network - Rede de longa distância, conecta redes em diferentes cidades ou países.
Intranet
Rede privada que usa tecnologias da Internet para uso interno de uma organização.
Internet
Rede mundial de computadores interconectados usando protocolos padronizados.
Topologia de rede
Forma como os dispositivos estão fisicamente ou logicamente conectados em uma rede.
Rede em Estrela
Topologia onde todos os dispositivos se conectam a um ponto central (hub ou switch).
Rede em Anel
Topologia onde os dispositivos formam um círculo fechado de conexões.
Rede em Ponte
Topologia que conecta duas ou mais redes diferentes através de um dispositivo ponte.
Bus
Topologia linear onde todos os dispositivos compartilham um mesmo meio de transmissão.
Host
Qualquer dispositivo conectado a uma rede que pode enviar ou receber dados.
Hostnames
Nomes únicos atribuídos a dispositivos em uma rede para identificação.
Cliente
Dispositivo ou software que solicita serviços ou recursos de um servidor.
Servidor
Dispositivo ou software que fornece serviços ou recursos para clientes na rede.
P2P
Peer-to-Peer - Arquitetura onde dispositivos atuam simultaneamente como cliente e servidor.

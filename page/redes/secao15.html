Protocolos Fundamentais de Rede

Esta seção apresenta os principais protocolos utilizados para comunicação em redes de computadores. Cada protocolo tem funções específicas e opera em diferentes camadas do modelo de rede.

Clique em qualquer termo para ver mais detalhes!

TCP
Transmission Control Protocol - Protocolo confiável de transporte orientado à conexão.
UDP
User Datagram Protocol - Protocolo de transporte rápido sem conexão.
IP
Internet Protocol - Protocolo fundamental para roteamento de pacotes na Internet.
HTTP
HyperText Transfer Protocol - Protocolo para transferência de páginas web.
HTTPS
HTTP Secure - Versão segura do HTTP com criptografia SSL/TLS.
FTP
File Transfer Protocol - Protocolo para transferência de arquivos.
SMTP
Simple Mail Transfer Protocol - Protocolo para envio de e-mails.
POP3
Post Office Protocol 3 - Protocolo para recebimento de e-mails.
IMAP
Internet Message Access Protocol - Protocolo avançado para acesso a e-mails.

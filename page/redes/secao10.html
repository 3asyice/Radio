Seção: Conceitos Básicos da Web

Esta página reúne 13 termos fundamentais relacionados à Web e à Internet. Cada cartão abre um modal com definição, exemplos práticos e links multimídia para aprofundar.

Dica: pressione ESC para fechar o modal.

Internet
Rede global de computadores que conecta dispositivos e serviços usando protocolos padronizados.
Web (WWW)
Serviço que roda sobre a Internet: páginas e recursos acessados via HTTP/HTTPS e navegadores.
HTTP
Protocolo de transferência de hipertexto usado para comunicação entre clientes e servidores web.
HTTPS
Versão segura do HTTP, que usa TLS/SSL para criptografar a comunicação.
URL
Endereço que localiza um recurso na Web (ex.: https://exemplo.com/pagina).
Domínio
Nome legível que representa um endereço na Internet (ex.: exemplo.com) — parte do sistema DNS.
DNS
Sistema de nomes de domínio que traduz domínios em endereços IP.
HTML
Linguagem de marcação usada para estruturar o conteúdo das páginas web.
CSS
Linguagem para descrever a apresentação (layout, cores, tipografia) do HTML.
JavaScript
Linguagem de programação para tornar páginas web interativas, no navegador e no servidor.
TCP/IP
Conjunto de protocolos básicos da Internet: IP para roteamento e TCP/UDP para transporte.
ISP
Provedor de Serviços de Internet — empresa que conecta residências e empresas à Internet.
Navegador (Browser)
Aplicativo que solicita, recebe e renderiza páginas web (ex.: Chrome, Firefox, Edge, Safari).
